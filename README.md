# Танковый фронт

Браузерная 3D-игра для **2–8 настоящих игроков**, без ботов и регистрации, с управлением на телефоне и ПК. Выберите устройство, введите ник, нажмите «Играть» и отправьте друзьям ссылку из кнопки «Пригласить». Телефон и ПК играют в общих комнатах.

**Единственный основной сайт: [tank-front.onrender.com](https://tank-front.onrender.com/).** Клиент и игровой сервер размещаются вместе на Render Free. Исходники: [tanks-online/tank-front](https://github.com/tanks-online/tank-front). Enzonic и Cloudflare для работы этой версии не нужны.

Выпуск **«Телефон + ПК» опубликован на Render 24 октября 2026 года**. Прошли 28 серверных и 18 клиентских тестов, TypeScript, сборка и GitHub Actions. На публичном сайте проверены общий бой режимов «Телефон» и «Компьютер», HTTPS/WSS и полный матч двух автоматических клиентов с уроном и возрождением. Поворот и узкие экраны проверены в браузере; совместная приёмка на физическом телефоне и ПК ещё требуется. Enzonic остановлен. [Статус приёмки](docs/ACCEPTANCE.md) · [Публикация на Render](docs/DEPLOY.md).

## Локальный запуск

Установите Node.js 24 LTS. В корне проекта:

```powershell
npm run setup
Copy-Item client/.env.example client/.env.local
```

В двух терминалах из корня запустите:

```powershell
npm run dev:server
```

```powershell
npm run dev:client
```

Откройте **http://localhost:5173/** в двух вкладках, выберите устройство и войдите с разными никами. В `client/.env.local` для этого запуска нужен `VITE_SERVER_URL=ws://localhost:3000/ws`. Сервер разрешает локальные origins на портах 5173 и 4173. Для 3D нужны WebGL 2 и аппаратное ускорение браузера.

Локальный адрес предназначен для вашего компьютера. Для совместной игры через интернет используйте публичный Render-сайт или разместите свою копию по [инструкции](docs/DEPLOY.md).

## Управление и правила

- При каждом входе явно выберите **«Телефон»** или **«ПК»**. Во время игры режим можно сменить в настройках. Выбор меняет управление, но не сервер и не комнату.
- **Телефон:** левый стик двигает танк по экрану; правый задаёт направление башни и автоматически стреляет при удержании. Двигаться и стрелять можно одновременно двумя пальцами. Для телефона по умолчанию включено низкое качество; настройка качества ПК сохраняется отдельно.
- Телефонный режим использует альбомное игровое поле. Где браузер позволяет, включаются нативный полный экран и блокировка ориентации. Если они недоступны и экран портретный, игра разворачивает интерфейс на 90° средствами CSS; сенсорные координаты учитывают этот поворот.
- **ПК:** WASD или стрелки двигают танк в направлениях экрана. Мышь задаёт прицел, ЛКМ или пробел стреляют. Shift включает медленный ход на 45% скорости, колесо меняет масштаб. TAB расширяет таблицу результатов, Escape открывает настройки.
- В настройках доступны звук, качество, выбор танка и классическое управление для ПК: W/S вперёд/назад, A/D поворот корпуса.
- В одиночку можно тренировать движение и стрельбу. При двух игроках начинается трёхминутный бой «каждый за себя». Побеждает большее число уничтожений, затем меньшее число смертей; одинаковый результат означает ничью.
- HUD показывает HP, счёт, время, пинг, соединение и перезарядку. Прицел реагирует локально, но право на выстрел и попадание определяет сервер.
- Возрождение через 3 секунды. Препятствия и границы блокируют танки и снаряды. Спавн выбирается вдали от соперников.
- «Играть» подбирает подходящую незавершённую комнату, иначе создаёт новую. Приглашение ведёт в конкретную комнату. На сервере максимум 4 комнаты по 8 игроков.
- Ник и настройки сохраняются в браузере. Краткий обрыв связи допускает восстановление игрока в течение 30 секунд. После перезапуска сервера комнаты и текущие результаты теряются; нужно войти в новый бой.

| Танк | HP | Скорость, ед/с | Урон | Перезарядка |
| --- | ---: | ---: | ---: | ---: |
| Стриж — лёгкий | 75 | 10 | 20 | 0,35 с |
| Бастион — средний | 110 | 7 | 30 | 0,6 с |
| Молот — тяжёлый | 160 | 5 | 45 | 1 с |

Карта «Песчаное депо» — арена 80 × 64 с семью непростреливаемыми укрытиями. Все модели и карта созданы процедурно: внешние модели, картинки, шрифты и платные API не используются.

## Сборка и проверка

```powershell
npm test
npm run build:hosted
```

`client/dist` содержит статические HTML/CSS/JS, `server/dist` — сервер Node.js. `build:hosted` задаёт `VITE_SERVER_URL=/ws`, если переменная не задана явно. Относительный Vite `base: './'` сохраняет пути к ресурсам. Для размещения вместе сервер раздаёт клиент через `STATIC_DIR=../client/dist`; запуск из корня — `npm start`.

Для локальной проверки этой сборки в PowerShell:

```powershell
$env:STATIC_DIR='../client/dist'
$env:PORT='3000'
$env:ALLOWED_ORIGINS='http://localhost:3000'
npm start
```

Откройте `http://localhost:3000/`. Полная инструкция Render, где эти адреса назначаются автоматически, находится в [DEPLOY.md](docs/DEPLOY.md).

28 серверных тестов проверяют симуляцию и настоящие WebSocket-соединения: управление, тренировку в ожидании, 2 и 8 игроков, урон, уничтожение, возрождение, завершение матча, подбор, ограничения сообщений, Origin и восстановление связи. 18 клиентских тестов проверяют сенсорный ввод и телефонный экран (11 и 7 соответственно). В локальном браузере проверены размеры 667 × 375, 844 × 390 и 390 × 844, общий бой режимов «Телефон» и «ПК», движение, огонь и перезарядка; ошибок консоли не было. Эти результаты не заменяют проверку опубликованного выпуска на реальном телефоне и ПК.

## Бесплатное размещение

Схема: один GitHub-репозиторий → один Render **Web Service Free**, который отдаёт сайт по HTTPS и игру по WSS на том же адресе.

| Поле Render | Значение |
| --- | --- |
| Repository | `https://github.com/tanks-online/tank-front` |
| Branch / Root Directory | `main` / пусто |
| Build Command | `npm run setup && npm run build:hosted` |
| Start Command | `npm start` |
| Instance Type | **Free** |
| Health Check Path | `/health` |
| Environment | `NODE_VERSION=24`, `NODE_ENV=production`, `NPM_CONFIG_INCLUDE=dev`, `VITE_SERVER_URL=/ws`, `STATIC_DIR=../client/dist` |

Render выдаёт `PORT` и `RENDER_EXTERNAL_URL`; вручную их не задавайте. Сервис использует управляемый HTTPS/WSS, отдельный шлюз не нужен. `render.yaml` описывает ту же схему.

Не добавляйте карту, платные ресурсы или автоматическое повышение тарифа. Free может засыпать и приостанавливаться при исчерпании квот; комнаты после перезапуска теряются. Перед размещением сверьте текущие бесплатные лимиты в панели. Подробности и порядок обновления через **Manual Deploy → Deploy latest commit** — в [инструкции](docs/DEPLOY.md).

Проверка опубликованного сервиса:

```powershell
npm run verify:remote -- --server https://tank-front.onrender.com --origin https://tank-front.onrender.com --directional
```

Для проверки полного матча добавьте `--full`. Затем выполните [приёмку](docs/ACCEPTANCE.md) на реальном телефоне и ПК: выберите соответствующие режимы, войдите по одному приглашению, одновременно двигайтесь и стреляйте двумя пальцами на телефоне, проверьте портретный разворот/альбомный экран, общий счёт, возрождение и конец матча. По возможности подключите устройства к разным сетям. Подробнее — [шаги проверки после deploy](docs/DEPLOY.md#4-проверить-публикацию).

## Архитектура и ограничения

Клиент — TypeScript, Vite, Three.js; сервер — Node.js, TypeScript и WebSocket. Сервер считает движение, столкновения, снаряды, HP, перезарядку, счёт и время. Клиент передаёт действия с возрастающим номером команды. Симуляция работает на 20 Гц, снимки — на 10 Гц; клиент плавно отображает их.

Сервер проверяет JSON и диапазоны значений, ограничивает payload 1 КиБ, частоту 60 сообщениями/с, число подключений и очередь отправки. Origin сравнивается с точным разрешённым списком. Это фильтр браузерных подключений, а не аутентификация небраузерных клиентов. Код комнаты — приглашение, не пароль.

Один процесс без базы данных; V8 heap ограничен 192 МиБ, WebSocket compression выключена. Free предназначен для небольших матчей с друзьями, а не гарантированной работы 24/7. Доступность нативного полного экрана и блокировки ориентации зависит от мобильного браузера; для портретного экрана предусмотрен CSS-разворот. Работа на конкретных физических телефонах требует отдельной проверки.

`VITE_SERVER_URL` — публичная настройка, встроенная в JavaScript. Не кладите секреты в `VITE_*`, клиент или Git. `.env*` исключены из репозитория, кроме безопасных `.env.example`. Токен восстановления игрока хранится только в памяти вкладки и сервера.
