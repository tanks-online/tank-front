## Автоматическая проверка нового выпуска

После deploy из корня проекта с установленными зависимостями:

```powershell
npm run verify:remote -- --server https://tank-front.onrender.com --origin https://tank-front.onrender.com --directional --full
```

Ожидаются успешные HTTPS, `/health`, `/rooms`, точный Origin, два WSS-соединения, экранное движение, стрельба, урон, смерть, возрождение, окончание матча и повторный бой. Чужой Origin должен быть отклонён WSS 403 без разрешения CORS. Проверка TLS остаётся включённой. Проверочные клиенты закрываются по окончании.

В автотестах серверной симуляции время может быть сокращено через параметры тестового экземпляра. Публичная проверка `--full` использует обычный трёхминутный матч без административного изменения HP, координат или таймера. Автопроверка и две вкладки одного ПК не доказывают работу двух физических устройств.

## Проверка с другом на другом компьютере

Нужны два компьютера с клавиатурой и мышью, желательно через разные сети; второй можно подключить через мобильную точку доступа. Сенсорного управления пока нет.

1. Игрок A открывает Render-сайт по HTTPS без предупреждений, вводит ник и нажимает «Играть». Пока он один, проверяет движение и стрельбу в тренировке, затем отправляет ссылку «Пригласить» игроку Б.
2. Б открывает приглашение на другом компьютере, вводит другой ник и нажимает «Играть». Оба видят свои ники и пинг в одной комнате; матч начинается при двух игроках, без ботов.
3. Проверить WASD/стрелки по экрану, медленный ход Shift, масштаб колесом, прицел мышью, выстрел ЛКМ/пробелом и индикатор перезарядки. Движение видно другому игроку. В настройках проверить классические W/S и A/D.
4. В прямой видимости стрелять до уменьшения HP, уничтожения, роста счёта и возрождения через 3 секунды. За препятствием попаданий нет; танки не проходят сквозь укрытия и другие танки.
5. Дождаться нуля таймера. Результаты совпадают на обоих компьютерах. «Ещё один бой» запускает новый раунд и сбрасывает счёт.
6. На одном компьютере отключить сеть на 5–10 секунд. Проверить сообщение о разрыве и восстановление игрока. После перезапуска сервера приложение должно сообщать об исчезнувшей комнате и позволять войти заново.
7. После выхода обоих и 15+ минут простоя проверить ожидание пробуждения Render, затем успешный вход. Не использовать постоянный внешний опрос ради обхода сна.
8. Проверить в кабинете план **Free**, отсутствие карты, платных ресурсов и повышения тарифа. При достижении квот остановка допустима, оплата не подключается.
