# Приёмка игры на Render

Основной адрес: **[tank-front.onrender.com](https://tank-front.onrender.com/)**. Клиент и сервер работают на одном Render Free; Enzonic остановлен. [Публикация](DEPLOY.md).

**Выпуск «Телефон + ПК», 24 октября 2026 года:** мобильное управление опубликовано. Оба режима играют на одном сервере и входят в одну комнату по приглашению. Выбор устройства меняет только управление и отображение. Ботов нет. Проверки в браузере и автоматические матчи пройдены; совместная проверка на физическом телефоне и ПК пока не зафиксирована.

## Как проверить телефон и ПК вместе

1. Оба игрока открывают основной HTTPS-сайт. Если видна старая версия, перезагружают страницу.
2. Игрок A выбирает «Компьютер», вводит ник, нажимает «Играть». Один игрок может ездить и стрелять в разминке.
3. A нажимает «Пригласить» и отправляет ссылку другу. Друг открывает её на телефоне, выбирает «Телефон», вводит другой ник и нажимает «Играть».
4. Оба видят два ника в одной комнате, таймер начинает отсчитывать три минуты. На телефоне таблица открывается кнопкой ≡.
5. На ПК проверить WASD/стрелки, прицел мышью, ЛКМ/пробел, Shift и масштаб колесом.
6. На телефоне удерживать левый стик для движения, правый — для наведения и стрельбы. Проверить оба стика одновременно двумя пальцами. Отпускание одного пальца не останавливает второй стик.
7. Повернуть телефон в обе ориентации. Арена остаётся горизонтальной. Если браузер не даёт нативную блокировку ориентации, портретная игровая область поворачивается на 90°; держать телефон боком. Проверить направление движения и башни после поворота. Кнопка ⛶ повторяет запрос полного экрана.
8. Свернуть браузер или открыть настройки во время движения и огня: управление останавливается. Вернуться, проверить стики. Переключить устройство в настройках, затем вернуть нужный режим.
9. В прямой видимости стрелять до уменьшения HP, уничтожения, роста счёта и возрождения через 3 секунды. За укрытием попаданий нет; танки не проходят сквозь препятствия и друг друга.
10. Дождаться нуля таймера. Итоговая таблица совпадает на обоих устройствах. «Ещё один бой» запускает новый раунд.
11. Отключить сеть одного устройства на 5–10 секунд. Проверить сообщение и восстановление. По возможности использовать разные сети: например, ПК через домашний интернет, телефон через мобильный.
12. После перезапуска Render текущие комнаты исчезают: вернуться в меню, войти заново и отправить новое приглашение. После 15+ минут простоя проверить ожидание пробуждения без постоянного внешнего опроса.

Для 3D нужен браузер с WebGL 2. Нативные fullscreen и блокировка ориентации зависят от браузера; CSS-поворот предусмотрен независимо от них. На телефоне по умолчанию низкое качество, для ПК качество сохраняется отдельно.

## Повторная автоматическая проверка

```powershell
npm test
npm run build:hosted
npm run verify:remote -- --server https://tank-front.onrender.com --origin https://tank-front.onrender.com --directional --full
```

Публичный `--full` использует настоящий трёхминутный матч без административного изменения HP, координат или таймера. Он создаёт временных проверочных клиентов и закрывает их в конце. Эти клиенты не являются игровыми ботами.
